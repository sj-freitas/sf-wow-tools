# Raid target markers

One image per raid target marker, named exactly: `Skull.png`, `Cross.png`, `Square.png`,
`Moon.png`, `Triangle.png`, `Diamond.png`, `Circle.png`, `Star.png`.

- PNG, JPEG or GIF, at most 256 KB (Discord's emoji limit). Square, around 64–128 px, looks best.
- Assignments show them instead of the marker's name ("Darkshivan tanks 💀"): the bot uploads each
  as a Discord emoji of the application, and the website shows the same file.
- A marker without an image is written as text, e.g. `[Circle]`.
