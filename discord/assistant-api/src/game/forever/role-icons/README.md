# Role icons

One image per raid role, named exactly: `Tank.png`, `Healer.png`, `Melee.png`, `Ranged.png`; and
for the raid setup, `Leader.png` (the event's leader), `Assist.png` (raid assist: the leader's
crown in silver) and `MasterLooter.png` (the loot bag, in the same round frame).

- PNG, JPEG or GIF, at most 256 KB (Discord's emoji limit). Square looks best.
- Sign-up posts use the roles for the columns' titles and in front of each person in the setup's
  groups; the leader, assist and master looter icons go after names in the setup. The website's
  Sign-ups and Raid setup pages show the same files.
  The bot uploads each as a Discord emoji of the application (a new image is uploaded as a new one).
- One without an image keeps its emoji: 🛡️ 💚 ⚔️ 🏹 👑 🥈 💰.
