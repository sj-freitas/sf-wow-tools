# Role icons

One image per raid role, named exactly: `Tank.png`, `Healer.png`, `Melee.png`, `Ranged.png`, and
`Leader.png` for the event's leader (whoever created it).

- PNG, JPEG or GIF, at most 256 KB (Discord's emoji limit). Square looks best.
- Sign-up posts use them for the role columns' titles, in front of each person in the raid setup's
  groups, and on the leader line; the website's Sign-ups and Raid setup pages show the same files.
  The bot uploads each as a Discord emoji of the application (a new image is uploaded as a new one).
- One without an image keeps its emoji: 🛡️ 💚 ⚔️ 🏹 👑.
