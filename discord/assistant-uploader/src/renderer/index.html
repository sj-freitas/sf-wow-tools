Guild Assistant Uploader

Uploads your professions each time the game saves them.

1 Upload key

The uploader needs a key to upload as you. It can only upload professions.

  1. Click Get an upload key: Guild Assistant opens in your browser (log in with Discord if it asks).
  2. Click Make a key, then Copy key.
  3. Paste it below and click Save.

2 Game folder

World of Warcraft’s folder: the one with _forever_ (or _classic_era_) in it.

    No GuildAssistantProfessions.lua in it yet. In game, open each profession’s window once, then type /ga-prof save: the game writes the file, and it’s uploaded right away.
